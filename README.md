# 🎯 AI Tutor Agent — Agentic Education System

An AI-powered multi-agent education system that generates grade-wise explanations, creates MCQs, reviews content quality, and automatically refines outputs.

This project demonstrates an **AI-native, agent-based architecture** built for scalable EdTech applications.

---

# 🚀 Project Overview

This system was developed as part of the **first-round assignment for Eklavya.me**.

The goal was to design an intelligent education agent capable of:

* 📚 Generating grade-wise topic explanations
* 📝 Creating MCQs for student practice
* 🔍 Reviewing content for clarity and correctness
* 🔁 Automatically refining low-quality outputs

The solution follows an **agentic AI pipeline** to simulate real-world AI-native workflows.

---

# 🧠 Architecture

## Multi-Agent Pipeline

```
User Input → Generator Agent → Reviewer Agent → Refinement Loop → Final Output
```

### 🤖 Generator Agent

Responsible for:

* Topic explanation generation
* MCQ creation
* Structured JSON output

---

### 🧠 Reviewer Agent

Evaluates generated content based on:

* Clarity
* Correctness
* Completeness
* Grade appropriateness

Provides structured feedback.

---

### 🔁 One-Pass Refinement Logic

If reviewer feedback fails quality thresholds:

* The system automatically refines the content
* Improves explanation quality
* Fixes MCQs
* Produces final validated output
